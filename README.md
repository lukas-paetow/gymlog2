# gymlog2
Full-stack mobile application for tracking my workouts. Written in TypeScript and ReactNative, to be used on my android phone. The plan is to make planning routines, logging them in the gym, and plotting the data as easy as possible.

## Local documentation

From `mobile/`, run `npm run docs` to generate the database reference.
Open `mobile/docs/api/index.html` in your browser. Regenerate after code changes.
